# Netflix ETL BigQuery Project

## Project Overview

This project focuses on cleaning, transforming, and preparing the Netflix Movies and TV Shows dataset for analytical purposes using Python and Pandas.

The project is designed as a beginner-to-intermediate data engineering and analytics workflow, starting from raw CSV preprocessing and continuing toward BigQuery-based analysis.

---

## Dataset

Dataset Information : 
| Information | Details |
|---|---|
| Dataset Name | Netflix Movies and TV Shows |
| Source | [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows) |
| Format | CSV |
| Total Rows | 8807 |
| Total Columns | 12 |

The cleaning process includes:
- handling missing values,
- removing duplicates,
- standardizing categorical data,
- converting data types,
- and preparing the dataset for analysis.
